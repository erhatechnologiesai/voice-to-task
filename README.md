# Voice-to-Task AI Assistant

An audio memo productivity tool that transcribes voice recordings, isolates distinct actionable tasks, identifies deadlines, and tags tickets for project management tools.

Part of the **50 AI Automation Projects Portfolio** by [ERHA TECHNOLOGIES](https://github.com/erhatechnologiesai).
